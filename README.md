🌤️ Weather Dashboard & Telegram Bot
Универсальный погодный сервис, состоящий из интерактивного веб-сайта и функционального Telegram-бота. 
Проект позволяет узнавать погоду как по названию города, так и по текущей геолокации.

🚀 Основные возможности
Web-интерфейс:
- Поиск погоды в реальном времени по названию города.
- Определение погоды «рядом со мной» с помощью браузерной геолокации (без перезагрузки страницы).
- Прогноз погоды на 5 дней с динамическими карточками.
- Живые фоны: Цвет сайта меняется в зависимости от состояния погоды (ясно, дождь, снег и т.д.).

Telegram-бот:
- Мгновенный поиск погоды по текстовому запросу.
- Специальная кнопка для отправки координат.
- Ссылка на основной веб-сайт в каждом ответе.

🛠️ Стек технологий:
- Backend: Python 3.x, Flask (веб-сервер), aiogram 3.x (движок бота).
- Frontend: HTML5, CSS3 (Flexbox, Backdrop-filter), JavaScript (Fetch API).
- API: OpenWeatherMap (данные о погоде).
- Deployment: GitHub, Render.com.

📦 Как запустить локально
Клонируйте репозиторий:
Bash
git clone https://github.com/твой-логин/название-проекта.git
cd название-проекта
Установите зависимости:
Bash
pip install -r requirements.txt
Настройте ключи доступа:
Откройте файлы app.py и bot.py и вставьте свои API-токены в соответствующие переменные.

Запустите проект:
- Для запуска сайта: python app.py
- Для запуска бота: python bot.py

🌍 Развертывание (Hosting)
Проект настроен для работы на платформе Render.
- Procfile позволяет запускать веб-сервер и бота одновременно в одном сервисе.
- Используется асинхронная архитектура для стабильной работы бота в фоновом режиме.
